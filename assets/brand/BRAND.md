# G5LIVE shared brand

A connected-node G mark with the existing G5LIVE name. The app title remains separate so each project keeps its identity under one family.

- Master artwork: `g5live.svg`, a scalable SVG with a built-in dark background.
- Palette: midnight `#10151d`, light text `#e8edf4`, blue `#a7d6ff`, amber `#dfa448`, green `#47bc83`.
- Motto: **Build · Understand · Apply**.
- Use the same artwork and spelling in READMEs, app headers, CLI descriptions and release material. Retain readable contrast and the mark's aspect ratio.
- The brand does not imply certification, professional registration or endorsement by training providers.

The first application pass covers repository/profile branding, the learning app header, CLI help descriptions and the game window title. Full in-game artwork, icons, splash screens and release social previews can follow later.
